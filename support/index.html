Peku Support

Get connected

Enable an OpenSSH server on your Mac or Linux computer. On macOS, enable Remote Login in System Settings. Make sure your iPhone or iPad can reach the computer, then pair using the Peku companion CLI or add an SSH connection manually.

Use Herdr workspaces

Herdr is optional. With Herdr installed and workspaces running on your computer, Peku can discover and attach to them. Without Herdr, you can open a regular SSH shell. Leaving a Herdr terminal detaches the client; it does not stop the computer's tasks.

Connect away from home

Set up Tailscale separately on your computer and mobile device and ensure your network permits access to the computer's ordinary SSH server. Tailscale SSH is a separate authentication feature and can take over port 22; Peku's public-key pairing requires ordinary OpenSSH. Peku does not host your computer or provide a VPN.

Connection failed

Check that the computer is awake, SSH is enabled, the address and port are correct, and the mobile device has network access. Retry the affected host. If the computer's SSH host key changed, verify the change on the computer before reconnecting. iOS can suspend connections in the background.

Image upload failed

The computer must provide the standard SFTP subsystem and allow the SSH user to write to its home directory. Peku uploads images to .peku/uploads. Retry the upload after restoring the connection or cancel it and select the images again.

Contact support

Include your Peku version, iOS version, computer operating system and the steps that reproduce the problem. If you attach a screenshot, remove passwords, private keys, host details and sensitive terminal output.
